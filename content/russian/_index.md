# API аннотирования документов – учебные материалы и примеры SDK

В этом руководстве вы узнаете, как **document annotation API** позволяет внедрять богатые функции аннотирования — такие как выделения, комментарии и фигуры — непосредственно в PDF, Word, Excel, PowerPoint и многие другие типы файлов. Независимо от того, создаёте ли вы совместный портал рецензирования, образовательное приложение или рабочий процесс с юридическими документами, API предоставляет вам единый, высокопроизводительный способ работы с аннотациями как в средах .NET, так и Java.

## Быстрые ответы
- **Что делает API аннотирования документов?** Он позволяет разработчикам добавлять, редактировать и управлять аннотациями более чем в 50 форматах документов без внешних зависимостей.  
- **Какие платформы поддерживаются?** .NET (Framework, Core, .NET 5/6) и Java (любой JDK 8+).  
- **Нужна ли лицензия для разработки?** Доступна бесплатная пробная версия; лицензия требуется для использования в продакшене.  
- **Могу ли я аннотировать PDF и файлы Office одним и тем же кодом?** Да — единый API обрабатывает PDF, Word, Excel, PowerPoint, изображения, HTML и многое другое.  
- **Возможна ли облачная развертка?** Абсолютно — можно запускать на Windows, Linux, macOS, Docker или любой облачной службе.

## Что такое API аннотирования документов?

API **document annotation API** — это кроссплатформенный SDK, позволяющий добавлять, редактировать и удалять аннотации в документах. Он поддерживает более 50 форматов, включая PDF, Word, Excel, PowerPoint, изображения и HTML, что позволяет работать с единой объектной моделью и избегать кода, специфичного для формата, при сохранении точности макета и метаданных. Такой единый подход сокращает время разработки до 70 % по сравнению с созданием отдельных обработчиков для каждого типа файлов.

## Почему стоит выбрать GroupDocs.Annotation?

GroupDocs.Annotation выделяется тем, что обрабатывает аннотации более чем для 50 типов файлов — включая PDF, Word, Excel, PowerPoint и изображения — без каких‑либо внешних зависимостей, таких как Adobe Reader или Microsoft Office. Его высокопроизводительный движок рендеринга обрабатывает документы со множеством сотен страниц менее чем за секунду на стандартных серверах, а встроенные инструменты совместной работы позволяют нескольким пользователям в реальном времени добавлять ветвящиеся комментарии.

- **Format independence** – Один API работает с более чем 50 типами документов, от PDF до электронных таблиц Excel.  
- **Rich annotation types** – Текстовая разметка, графические фигуры, комментарии и ветвящиеся ответы в режиме совместной работы включены по умолчанию.  
- **No external dependencies** – Не требуется Adobe Reader, Office или другие сторонние инструменты.  
- **High‑performance rendering** – Регулируемое качество и разрешение для быстрой генерации превью; типичные PDF‑файлы из 300 страниц рендерятся за 0,8 секунды на виртуальной машине с 2 CPU.  
- **Cross‑platform support** – Бесшовно работает на Windows, Linux, macOS, Docker или в безсерверных средах.

## Основные сценарии использования
- **Document review workflows** – Позволяет рецензентам добавлять комментарии и одобрять изменения в реальном времени.  
- **Educational applications** – Учителя могут выделять учебный материал и давать обратную связь непосредственно в документе.  
- **Legal document processing** – Помечать пункты, добавлять заметки и отслеживать изменения в контрактах.  
- **Healthcare documentation** – Выделять критическую информацию о пациенте, соблюдая требования HIPAA.  
- **Construction & engineering** – Аннотировать чертежи, схемы и технические рисунки с точными измерениями.

## Часто задаваемые вопросы

**Q: Можно ли использовать API аннотирования документов в коммерческом продукте?**  
A: Да. Для продакшн‑развертываний требуется действующая лицензия GroupDocs, а бесплатная пробная версия доступна для оценки.

**Q: Поддерживает ли API PDF‑файлы, защищённые паролем?**  
A: Абсолютно. Вы можете указать пароль при открытии документа, и все операции аннотирования работают прозрачно.

**Q: Какие версии .NET совместимы?**  
A: SDK поддерживает .NET Framework 4.5+, .NET Core 3.1+, .NET 5 и .NET 6+.

**Q: Как API обрабатывает большие файлы?**  
A: `Document.OptimizeResources()` освобождает кэшированные данные и снижает использование памяти во время операций аннотирования. Он потоково передаёт содержимое и предлагает методы оптимизации памяти, такие как `Document.OptimizeResources()`, чтобы сохранять низкое потребление памяти даже при работе с многогигабайтными файлами.

**Q: Есть ли встроенная поддержка облачных хранилищ?**  
A: Да. Вы можете загружать и сохранять документы напрямую из Amazon S3, Azure Blob Storage, Google Cloud Storage и других облачных провайдеров.
